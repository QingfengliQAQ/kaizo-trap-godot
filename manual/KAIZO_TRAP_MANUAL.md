## 02 / 控制器说明（CONTROLLER: A · C · G · T）

本主机采用特殊的四碱基按键布局（**A / C / G / T**），键盘映射如下：

| 复古手柄按键 | 对应键盘按键 | 功能说明 |
| :--- | :--- | :--- |
| **D-Pad 十字键** | `W A S D` 或 `方向键` | 左右奔跑 / 上下瞄准踢壳 / 下蹲 |
| **`A` 键** | `Space` / `Z` / `K` | 变速跳跃（点按低跳、长按高跳）& 贴墙蹬墙跳 |
| **`T` 键** | `Shift` / `X` / `J` | 冲刺加速（Sprint） |
| **`G` 组合键** | 移动时 `Down + Shift/X` | **贴地滑铲（Slide）**，钻过低矮电击刺通道 |
| **`G + A` 组合** | 滑铲/下蹲时按 `Space/Z` | **大跳（Long Jump）**，低弧度超远飞跃 |
| **`C` 键** | `E` / `C` | 拾取/踢出金属菊石壳；按住 **`Up + C`** 可向上踢壳完成**空中踩壳跳（Shell Jump）**！ |

### 快捷系统键
* `Tab` / `M`：打开/关闭游戏内复古说明书
* `` ` `` / `F1`：呼出神秘系统终端 **`ZhugeDOS 14`**
* `F2`：打开 **TAS / 辅助菜单**（切换经典/辅助模式、慢动作、显露隐藏块轮廓、实时按键显示、切换 Arrange Mode 二周目）
* `F5` / `F7`：辅助模式下的即时存档 / 读档（Save State）
* `R`：当前房间瞬间重试
* **鼠标右键**：**CRT 显像管检视光标**（*……也许有些东西不该只用角色去碰？*）

## 03 / 平台地狱生存守则（SURVIVAL GUIDE）

1. **小心头顶的椰子（1-1）**：看似平静的热带开局，椰子随时可能砸下来——*如果你以后有机会原路返回，千万别忘了它*。
2. **黄金八卦隐形块（Invisible Bagua Block）**：起跳前一切看似空旷？当你跳到半空时，脚顶可能会“咚”地撞出一块刻着八卦符号的黄金砖，直接把你送进尖刺坑。
3. **永远不要轻信指向右边的木牌（1-2）**：越是写着 `GO ->` 的地方，真正的钥匙越可能藏在**下方**。
4. **二周目里世界（Arrange Mode）**：如果你以为碰到终点红旗就通关了……祝你好运。二周目的冰雪关卡还会卷起致盲暴风雪。
